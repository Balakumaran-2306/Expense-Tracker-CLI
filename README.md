# 💰 Expense Tracker - Personal Finance Management System

A CLI-based Expense Tracker application developed using Python and SQLite for managing personal income and expenses efficiently.

## 🚀 Features

- User Authentication
- Add Income & Expenses
- View Transactions
- Update & Delete Transactions
- Monthly Reports
- Budget Check
- Expense Chart Visualization
- CSV Export
- SQLite Database Integration
- Exception Handling

## 🛠️ Technologies Used

- Python
- SQLite
- Matplotlib

## ▶️ How to Run

1. Install Python
2. Install matplotlib
pip install matplotlib

3. Run the project
python expense_tracker.py
